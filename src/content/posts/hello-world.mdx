# 你好，世界！

欢迎来到我的博客！这是我的第一篇文章。

## 为什么要写博客？

写博客是一种很好的方式来记录自己的思考和学习历程。它不仅可以帮助自己整理思路，还能与他人分享知识和经验。

## 这个博客用了什么技术？

这个博客使用了以下技术栈：

- **Astro** — 现代化的静态站点框架
- **Tailwind CSS** — 原子化 CSS 框架
- **MDX / Markdoc** — 内容编写格式
- **GitHub Pages** — 部署平台

## 代码示例

这里是一段 TypeScript 代码（带可选标题）：

```typescript title="src/types/blog.ts"
interface BlogPost {
  title: string;
  description: string;
  pubDate: Date;
  tags: string[];
}

function greet(name: string): string {
  return `你好，${name}！欢迎来到我的博客。`;
}

console.log(greet('世界'));
```
